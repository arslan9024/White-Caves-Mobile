# White-Caves Mobile — Antigravity Engineering Rules

## 1. Core Directives
- **Cross-Platform Parity:** Ensure components render smoothly on both iOS and Android.
- **Biometric & Secure Storage:** Auth tokens and sensitive biometric session tokens must be stored in encrypted device storage (KeyStore / Keychain).
- **Offline & Optimistic UI:** Provide caching and graceful offline handling for property listings and client inquiries.
